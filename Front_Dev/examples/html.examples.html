Estrutura Básica HTML

estrutura-basica.html 
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Minha Primeira Página</title>
    <meta name="description" content="Uma página web de exemplo">
    <meta name="keywords" content="HTML, exemplo, aprendizado">
    <meta name="author" content="Seu Nome">
    <link rel="stylesheet" href="style.css">
    <link rel="icon" href="favicon.ico" type="image/x-icon">
</head>
<body>
    <!-- Conteúdo da página vai aqui -->
    <h1>Olá, Mundo!</h1>
    <p>Esta é minha primeira página HTML.</p>
    
    <script src="script.js"></script>
</body>
</html>

Olá, Mundo!

Esta é minha primeira página HTML.

A estrutura básica inclui:

  • DOCTYPE: Define a versão do HTML
  • html: Elemento raiz
  • head: Metadados e recursos
  • body: Conteúdo visível

Elementos Essenciais da Estrutura

<!DOCTYPE html>

Declara que este é um documento HTML5. Sempre deve ser a primeira linha.

<html lang="pt-br">

Elemento raiz. O atributo "lang" define o idioma para acessibilidade e SEO.

<meta charset="UTF-8">

Define a codificação de caracteres. Evita problemas com acentos e caracteres especiais.

<meta name="viewport">

Configura a página para dispositivos móveis. Essencial para design responsivo.

🏗️ Comparação: Div vs Tags Semânticas

Entenda por que tags semânticas são melhores que divs genéricas:

Com DIVs (Ruim)

  • Estrutura pouco clara
  • Problemas de acessibilidade
  • SEO prejudicado
  • Manutenção difícil
  • Leitores de tela confusos

Com Tags Semânticas (Bom)

  • Estrutura clara e organizada
  • Excelente acessibilidade
  • SEO otimizado
  • Fácil manutenção
  • Melhor experiência para leitores de tela
Analogia Prática

Imagine uma biblioteca: Usar apenas DIVs é como ter todos os livros em caixas sem rótulo. Tags semânticas são como organizar em seções claras: "Romance", "Técnico", "Infantil". Ambos guardam os livros, mas um é muito mais útil!

  • Email (email, obrigatório)

Crie um formulário de cadastro com validação HTML5:

  • Confirmação de senha (deve ser igual à senha)
  • Termos de uso (checkbox obrigatório)
  • Data de nascimento (date, maior de 18 anos)
