HTML Básico - Fundamentos

Comece do zero aprendendo a estrutura básica de páginas web, tags essenciais e como criar seu primeiro documento HTML.

Estrutura Básica HTML

Explicação Simples:

Todo documento HTML tem uma estrutura básica que inclui a declaração DOCTYPE, elemento html, head (cabeçalho) e body (corpo). É como a planta de uma casa.

Analogia:

Imagine um livro: O DOCTYPE é o tipo de livro (ficção, técnico), a tag html é o livro inteiro, head é a capa/índice, e body é o conteúdo do livro.

Exemplo Prático:

<!DOCTYPE html> <html lang="pt-br"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Minha Primeira Página</title> </head> <body> <h1>Olá, Mundo!</h1> <p>Minha primeira página HTML.</p> </body> </html>

🧪 Experimente Modificar:

Olá, Mundo!

Minha primeira página HTML.

Erros Comuns:

  • Esquecer o DOCTYPE (a página pode renderizar incorretamente)
  • Não definir charset UTF-8 (problemas com acentos e caracteres especiais)
  • Esquecer fechar tags (causa problemas de renderização)
  • Colocar conteúdo visível dentro do head (não será exibido)

Tags de Texto e Formatação

Explicação Simples:

HTML possui diversas tags para formatar texto: cabeçalhos (h1-h6), parágrafos (p), negrito (strong), itálico (em), listas (ul, ol, li) e muito mais.

Analogia:

Pense em um documento do Word: h1 é o título principal, h2 são subtítulos, p são parágrafos, strong é negrito, em é itálico. Cada tag tem uma função específica na formatação.

Exemplo Prático:

HTML Intermediário - Links, Imagens e Tabelas

Aprenda a conectar páginas com links, adicionar imagens e criar tabelas para organizar dados.

Links e Imagens

Explicação Simples:

Links (<a>) conectam páginas na web. Imagens (<img>) exibem conteúdo visual. Ambos são fundamentais para qualquer site.

Analogia:

Links são como portas entre salas (páginas). Imagens são como quadros nas paredes. As portas levam você a outros lugares, os quadros embelezam o ambiente.

Exemplo Prático:

Experimente Links:

Experimente Imagens:

Os links e imagens aparecerão aqui.

<!-- Link básico --> <a href="https://www.exemplo.com">Visite Exemplo.com</a> <!-- Link que abre em nova aba --> <a href="https://www.exemplo.com" target="_blank"> Abrir em nova aba </a> <!-- Imagem básica --> <img src="foto.jpg" alt="Descrição da foto"> <!-- Imagem com dimensões --> <img src="foto.jpg" alt="Descrição" width="300" height="200">
Dica Importante:

Sempre use o atributo alt em imagens! Ele é essencial para:

  • Acessibilidade (leitores de tela para deficientes visuais)
  • SEO (os buscadores entendem o conteúdo da imagem)
  • Exibição alternativa quando a imagem não carrega

Tabelas HTML

Explicação Simples:

Tabelas organizam dados em linhas e colunas. São úteis para exibir informações tabulares como calendários, grades de preços ou dados comparativos.

Analogia:

Uma tabela HTML é como uma planilha do Excel: tem linhas (tr), células (td), cabeçalhos (th) e pode mesclar células (colspan/rowspan) como "mesclar células" no Excel.

HTML Avançado - Formulários e Semântica

Domine formulários interativos e tags semânticas para criar sites acessíveis e otimizados para SEO.

Formulários HTML5

Explicação Simples:

Formulários coletam dados do usuário. HTML5 trouxe novos tipos de input (email, date, range) e validação nativa.

Analogia:

Um formulário HTML é como uma ficha de cadastro em papel, mas interativa. Cada campo (input) é uma pergunta, e o botão submit é como entregar a ficha preenchida.

Exemplo Prático:

Formulário de Contato Interativo:

5
<!-- Formulário HTML5 com validação --> <form> <!-- Campo de texto --> <label for="nome">Nome:</label> <input type="text" id="nome" required> <!-- Campo de email --> <label for="email">Email:</label> <input type="email" id="email" required> <!-- Select --> <label for="pais">País:</label> <select id="pais"> <option>Brasil</option> <option>EUA</option> </select> <!-- Botão submit --> <button type="submit">Enviar</button> </form>

HTML Semântico

Explicação Simples:

HTML semântico usa tags que descrevem seu significado (header, nav, article) em vez de apenas sua aparência (div, span). Isso melhora acessibilidade e SEO.

Analogia:

Imagine uma biblioteca: Usar apenas divs é como ter todos os livros em caixas sem rótulo. HTML semântico é como organizar em seções: "Romance", "Técnico", "Infantil". Ambos guardam livros, mas um é muito mais útil!

Exemplo Prático:

🏗️ Comparação: DIVs vs HTML Semântico

Com DIVs (Antigo)

<div id="header">...</div> <div class="nav">...</div> <div class="content">...</div> <div id="footer">...</div>
  • Estrutura pouco clara
  • Problemas de acessibilidade
  • SEO prejudicado
  • Manutenção difícil

Com HTML Semântico (Moderno)

<header>...</header> <nav>...</nav> <main>...</main> <footer>...</footer>
  • Estrutura clara e organizada
  • Excelente acessibilidade
  • SEO otimizado
  • Fácil manutenção

📋 Tags Semânticas Principais:

Tag Função Quando Usar
<header> Cabeçalho da página ou seção Logo, menu principal, introdução
<nav> Navegação principal Menu do site, links de navegação
<main> Conteúdo principal único Conteúdo central da página
<article> Conteúdo independente Post de blog, notícia, artigo
<section> Seção temática Capítulo, parte de conteúdo
<aside> Conteúdo relacionado Barra lateral, publicidade
<footer> Rodapé da página ou seção Informações de contato, copyright
Regra Simples:

Se você está usando uma div e precisa adicionar uma classe como "header" ou "footer", provavelmente deveria usar uma tag semântica em vez disso!
