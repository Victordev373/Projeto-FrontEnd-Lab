CSS Básico - Fundamentos

Aprenda os conceitos essenciais do CSS: seletores, box model, cores, tipografia e os primeiros passos para estilizar páginas web.

Seletores CSS

Explicação Simples:

Seletores são como "endereços" que dizem ao CSS quais elementos HTML devem receber determinados estilos.

Analogia:

Imagine que você é um decorador de interiores. Os seletores são como os nomes dos cômodos que você vai decorar: ".sala-de-estar", "#quarto-principal", "mesa".

Exemplo Prático:

seletores.css 
/* Seletor de elemento - todas as tags 
 */
p {
    color: #333;
    line-height: 1.6;
}

/* Seletor de classe - elementos com class="destaque" */
.destaque {
    background-color: yellow;
    padding: 10px;
}

/* Seletor de ID - elemento com id="cabecalho" */
#cabecalho {
    background: linear-gradient(90deg, #6a11cb, #2575fc);
    color: white;
}

/* Seletor descendente - 
  •  dentro de 
       */
ul li {
    margin-bottom: 5px;
}

/* Seletor de pseudo-classe - botão ao passar mouse */
button:hover {
    background-color: #2575fc;
    transform: scale(1.05);
}

    Experimente diferentes seletores:

    Título da Página

    Este parágrafo tem a classe "destaque".

    Este é um parágrafo normal.

    Erros Comuns:

    • Usar ID (#) para estilos reutilizáveis (use classes)
    • Esquecer de fechar chaves {}
    • Seletores muito genéricos que afetam elementos indesejados
    • Confundir .classe com #id

    Box Model

    Explicação Simples:

    Todo elemento HTML é uma "caixa" com conteúdo, padding (preenchimento interno), border (borda) e margin (margem externa).

    Analogia:

    Imagine um quadro na parede: O conteúdo é a foto, o padding é o espaço entre a foto e a moldura, a border é a moldura em si, e a margin é o espaço entre a moldura e a parede.

    Exemplo Prático:

    Controles do Box Model

    Visualização

    Conteúdo
    ← Padding →
    ← Border →
    ← Margin →
    Largura total: -
    Altura total: -
    box-model.css 
    .caixa {
    /* Conteúdo: 200x100 pixels */
    width: 200px;
    height: 100px;
    
    /* Padding: espaço interno */
    padding: 20px;
    
    /* Border: linha ao redor */
    border: 3px solid #00ff88;
    
    /* Margin: espaço externo */
    margin: 15px;
    
    /* Largura total = 200 + (20*2) + (3*2) = 246px */
    /* Altura total = 100 + (20*2) + (3*2) = 146px */
}

/* box-sizing: border-box faz a mágica! */
.caixa-inteligente {
    box-sizing: border-box;
    width: 200px; /* Inclui padding e border! */
    padding: 20px;
    border: 3px solid #00ff88;
}

    Erros Comuns:

    • Esquecer do box-sizing: border-box (causa cálculos errados)
    • Usar margin negativa sem necessidade
    • Confundir padding (interno) com margin (externo)
    • Não considerar o box model ao calcular layouts

    CSS Intermediário - Layouts Modernos

    Domine Flexbox, Grid, posicionamento e crie layouts responsivos que se adaptam a qualquer dispositivo.

    Flexbox

    Explicação Simples:

    Flexbox é um sistema de layout unidimensional que organiza elementos em uma linha ou coluna, com controle total sobre alinhamento, distribuição e ordem.

    Analogia:

    Imagine uma prateleira de livros (container flex) onde você pode organizar os livros (itens flex) de várias formas: alinhados à esquerda, centralizados, com espaços iguais entre eles, ou até mudar a ordem dos livros.

    Exemplo Prático:

    Controles Flexbox:

    Item 1
    Item 2
    Item 3
    Item 4
    flexbox.css 
    /* Container flex */
.container {
    display: flex; /* Ativa o flexbox */
    flex-direction: row; /* linha (padrão) ou column */
    justify-content: center; /* alinha horizontalmente */
    align-items: center; /* alinha verticalmente */
    gap: 20px; /* espaço entre itens */
    flex-wrap: wrap; /* quebra linha se necessário */
}

/* Itens flex */
.item {
    flex: 1; /* cresce igualmente */
    min-width: 200px; /* largura mínima */
}

.item-destaque {
    flex: 2; /* ocupa o dobro do espaço */
    order: -1; /* aparece primeiro */
}

/* Layout responsivo com flexbox */
@media (max-width: 768px) {
    .container {
        flex-direction: column;
    }
}

    📋 Propriedades Principais do Flexbox:

    Propriedade Valores Comuns Descrição Exemplo
    display flex, inline-flex Define o container como flex display: flex;
    flex-direction row, column, row-reverse Direção dos itens flex-direction: column;
    justify-content center, space-between, flex-start Alinhamento horizontal justify-content: space-between;
    align-items center, stretch, flex-start Alinhamento vertical align-items: center;
    flex-wrap wrap, nowrap, wrap-reverse Quebra de linha flex-wrap: wrap;
    gap 10px, 1rem, 2em Espaço entre itens gap: 20px;

    CSS Grid

    Explicação Simples:

    Grid é um sistema de layout bidimensional que cria grades com linhas e colunas, permitindo posicionamento preciso de elementos em uma matriz.

    Analogia:

    Imagine um tabuleiro de xadrez onde cada casa é uma célula. Você pode posicionar peças em células específicas, fazer uma peça ocupar várias casas, ou criar áreas nomeadas no tabuleiro.

    Exemplo Prático:

    Layout de Grade Simulado:

    Cabeçalho (col 1-3)
    Menu
    Conteúdo Principal
    Sidebar
    Rodapé (col 1-4)
    grid.css 
    /* Container grid */
.site {
    display: grid;
    /* 3 colunas: 200px auto 300px */
    grid-template-columns: 200px auto 300px;
    /* 3 linhas: cabeçalho, conteúdo, rodapé */
    grid-template-rows: 100px auto 100px;
    /* Áreas nomeadas */
    grid-template-areas:
        "cabecalho cabecalho cabecalho"
        "menu conteudo sidebar"
        "rodape rodape rodape";
    gap: 20px;
}

/* Posicionando elementos */
.cabecalho {
    grid-area: cabecalho;
    background: linear-gradient(90deg, #6a11cb, #2575fc);
}

.menu {
    grid-area: menu;
    background: #1a1a2e;
}

.conteudo {
    grid-area: conteudo;
    background: white;
    color: #333;
}

.sidebar {
    grid-area: sidebar;
    background: #f0f0f0;
}

.rodape {
    grid-area: rodape;
    background: #16213e;
}

/* Grid responsivo */
@media (max-width: 768px) {
    .site {
        grid-template-columns: 1fr;
        grid-template-areas:
            "cabecalho"
            "menu"
            "conteudo"
            "sidebar"
            "rodape";
    }
}

    CSS Avançado - Animações & Performance

    Aprenda animações CSS3, variáveis CSS, otimização de performance e técnicas profissionais para produção.

    Animações e Transições CSS

    Explicação Simples:

    CSS permite criar animações suaves e transições entre estados de elementos, melhorando a experiência do usuário sem JavaScript.

    Analogia:

    Imagine um interruptor de luz: a transição seria como um dimmer que suavemente muda do escuro para o claro, enquanto a animação seria como uma luz piscando em padrões específicos.

    Exemplo Prático:

    Tipos de Animação:

    animacoes.css 
    /* Transições suaves */
.botao {
    background: #6a11cb;
    color: white;
    padding: 12px 24px;
    border: none;
    border-radius: 8px;
    transition: all 0.3s ease;
}

.botao:hover {
    background: #2575fc;
    transform: translateY(-3px);
    box-shadow: 0 10px 20px rgba(106, 17, 203, 0.3);
}

/* Animações com @keyframes */
@keyframes pulsar {
    0% { transform: scale(1); }
    50% { transform: scale(1.1); }
    100% { transform: scale(1); }
}

.elemento-pulsante {
    animation: pulsar 2s infinite ease-in-out;
}

/* Animação de entrada */
@keyframes slideIn {
    from {
        opacity: 0;
        transform: translateY(30px);
    }
    to {
        opacity: 1;
        transform: translateY(0);
    }
}

.novo-elemento {
    animation: slideIn 0.6s ease forwards;
}

/* Controle de animação */
.pausavel {
    animation-play-state: running;
}

.pausavel:hover {
    animation-play-state: paused;
}

    Variáveis CSS (Custom Properties)

    Explicação Simples:

    Variáveis CSS permitem armazenar valores reutilizáveis (cores, fontes, tamanhos) em um único lugar, facilitando a manutenção e criação de temas.

    Analogia:

    Imagine que você está pintando uma casa. Em vez de lembrar o código exato de cada cor, você dá nomes às cores: "azul-principal", "branco-teto", "marrom-porta". Se quiser mudar o azul, altera apenas uma vez.

    Exemplo Prático:

    Temas com Variáveis CSS:

    Demonstração de Tema

    Este bloco usa variáveis CSS para mudar de tema dinamicamente.

    variaveis.css 
    /* Definindo variáveis no :root (global) */
:root {
    --cor-primaria: #6a11cb;
    --cor-secundaria: #2575fc;
    --cor-sucesso: #00ff88;
    --cor-fundo: #1a1a2e;
    --cor-texto: #ffffff;
    --espacamento: 20px;
    --raio-borda: 12px;
    --sombra: 0 10px 30px rgba(0, 0, 0, 0.3);
}

/* Usando variáveis */
.botao {
    background: var(--cor-primaria);
    color: var(--cor-texto);
    padding: calc(var(--espacamento) / 2) var(--espacamento);
    border-radius: var(--raio-borda);
    box-shadow: var(--sombra);
}

/* Alterando variáveis em diferentes contextos */
@media (prefers-color-scheme: light) {
    :root {
        --cor-fundo: #ffffff;
        --cor-texto: #333333;
    }
}

/* Tema escuro personalizado */
.tema-escuro {
    --cor-fundo: #0a0a1a;
    --cor-texto: #f0f0f0;
}

/* Mudando variáveis com JavaScript */
document.documentElement.style.setProperty('--cor-primaria', '#ff0055');
